## Assignment

Assignment 7 will give us students the opportunity to work in an Agile
methodology environment while working efficiently in a group with other students.
Our project as a group will be to develop a Python application that intakes,
processes, and outputs financial transaction data. Overall, this project will
give us invaluable experience with practicing essential skills for a professional
software developer, such as collaborative environment, effective communication,
and adhering to industry standards.
